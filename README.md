# JARVIS — M-Sharbis\n\nAsistente personal web, diseñado primero para Android.\n\n## Versión 0.2\n- Interfaz móvil futurista y panel de conversación.\n- Reconocimiento de voz cuando el navegador lo soporta.\n- Selector de voces españolas disponibles en el dispositivo.\n- Ajuste de tono y velocidad de síntesis.\n- Memoria local para notas.\n- Investigación de Wikipedia en español con enlaces a las fuentes.\n- Búsqueda general mediante enlace a Google.\n- PWA con caché de archivos principales.\n\n## Cómo hablarle\n- «¿Qué hora es?»\n- «Recordá llamar mañana».\n- «Mostrame mis notas».\n- «Investigá historia de la Patagonia».\n- «Buscá en Internet energías renovables».\n\n## Voz masculina\nEl selector muestra las voces en español instaladas en Android/navegador. Se priorizan nombres que suelen identificar voces masculinas, pero los nombres no garantizan el género. La elección y el tono se guardan localmente. Para instalar o cambiar voces, revisá los ajustes de texto a voz del dispositivo.\n\n## Límites\nLa voz depende de las voces instaladas. El reconocimiento de voz depende del navegador, permisos y servicios del dispositivo. Wikipedia consulta su API pública; la búsqueda general abre Google en otra pestaña. Esta versión aún no incluye un modelo de IA conversacional ni acceso universal a sitios web. La memoria no se sincroniza entre dispositivos.\n\n## Publicación\nGitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.\n\nURL prevista: https://eliasmartinezcultural-glitch.github.io/M-Sharbis/\n\n## Seguridad\nNo guardar claves privadas ni tokens en JavaScript público. La futura conexión con IA deberá pasar por un backend o servicio seguro.\n
